JamesOS for the M-VAVE FM-1

This is a community build that adds MIDI output (sequencer notes and MIDI clock) to JamesOS 1.0a, an alpha. It has not been qualified on hardware. Installing firmware can overwrite saved projects or leave the FM-1 unresponsive. Use it at your own risk.

Install or update

  1. Connect the FM-1 by USB with a data cable. Use Chrome or Edge on a computer, or Chrome on Android.
  2. Close other apps and tabs that use MIDI.
  3. Press Install and allow MIDI access.

An FM-1 on the official firmware gets JamesOS in two passes: the first writes the JamesOS base with its boot configuration, the second updates it to this build. Press Install again when the first pass is done. An FM-1 on another official version (such as V16), SLOOP or another community firmware must return to the official V15 first (below).


  
Do not unplug the USB cable while writing. If an install is cut off, replug the cable and press the same button again:
    the FM-1 stays in update mode until the write is finished.


  

  
Return to the official firmware (V15)

  
Download the official FM-1 V15,
    FM-1_015.fwsc,
    which M-VAVE publishes in its fm1_open repository
    (m-vave.com now offers only V16), and select it here unmodified. The file is checked in this browser and is not sent anywhere.

  
The official firmware cannot open the projects of JamesOS or SLOOP. Back them up first with that firmware's own tools.
    From JamesOS this return is not yet confirmed on hardware; from SLOOP it is SLOOP's own documented path.

  

  

  

  
M-VAVE's own updater, M-UPGRADE, works too.
