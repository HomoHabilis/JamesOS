# HD UI font notice

The HD interface (built with `BR_UI_HD=1`) draws anti-aliased text from glyph
bitmaps that are derived from the **Chakra Petch** typeface. Those bitmaps, and
only they, are under the SIL Open Font License 1.1. The rest of JamesOS keeps
its own licence (see `LICENSE` and `THIRD-PARTY-NOTICES.md`).

No Reserved Font Name is declared in the font's copyright string or in

## What the firmware contains

`firmware/src/james_font_hd.h` holds rasterised glyph coverage bitmaps
(2 bits per pixel by default), generated by `tools/gen_hd_font.py` from the font
file above, together with spacing data derived from them. The generator reads
the outlines with fontTools, fits each glyph into the JamesOS pixel font's
glyph box and to the pixel grid (horizontal squeeze, stem and zone snapping)
and rasterises it at the sizes the UI uses. Two glyphs are modified beyond
that: the generator adds a foot under 1 (as wide as 0, so 1 fills the tabular
digit cell and differs from I) and a dot inside 0 (so it differs from O). The
spacing data are a per-glyph advance (the fitted ink width plus a fixed gap,
capped at the pixel font's advance; digits share one tabular advance) and a
short pair-kerning table measured on the rasterised glyphs; they are computed
by the generator, not copied from the font's own metrics or kerning tables. No
font file, outline or font program is embedded in the firmware; only these
bitmaps and spacing data, which form a Modified Version of the Font Software
under the OFL and stay under the OFL. The generated header carries the
copyright line and points to this notice.

The font file and its `OFL.txt` are kept unmodified in `tools/fonts/chakrapetch/`
(OFL condition 2: the licence travels with the font), so regenerating needs no
download.

Distribution note: OFL condition 2 asks that copies carry the copyright notice
and this licence. Keep this file (or the licence text below) with any source or
binary distribution of firmware built with `BR_UI_HD=1`.

Earlier HD builds (up to `unified` c08584e) used Inter SemiBold 4.000
(Copyright 2016 The Inter Project Authors, OFL 1.1, https://github.com/rsms/inter;
`Inter-SemiBold.otf`, SHA-256 `bd68706b7bf8b3c580ae57685a2116bb1704b3a9998309ccfec7cd486f8a593e`).
The generator can still produce that header (`tools/gen_hd_font.py --help`);
firmware built from it carries Inter's copyright notice under the same licence.
