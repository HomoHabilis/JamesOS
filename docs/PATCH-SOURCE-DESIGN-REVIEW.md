# Patch source design review

The existing OSC AVG and MIX AVG are signed block averages. They retain their saved IDs and behavior; they are not envelope followers. A useful follower should rectify samples before averaging, smooth attack and release independently, and expose a unipolar level with documented scaling. It should be a new source ID, with a defined track or mix tap and a one-block delay to avoid feedback within the current audio graph.

A basic per-track follower would require one absolute-value operation and one accumulation for each of up to 4 × 256 samples per block, plus four smoothing updates, about 16 bytes for four 32-bit states, and any temporary accumulators and control logic. A mix follower also needs a defined mono/stereo combination and its own reduction. These are operation and state counts, not measured device timing: memory placement and CPU scheduling determine the actual cost. Demanding polyphony tests have reached or exceeded 90% of the deadline on MODAL, leaving little headroom in the worst measured case. No reliable device timing has yet been collected for a rectified follower, so it is deferred instead of spending that headroom on an unmeasured audio-loop addition. Prototype it behind a build flag, compare worst-case deadline and pool/RAM use with and without the follower across all models and active filters/FX, and add it only if the 90% profile is maintained.

A valid enabled FILTER ENV patch replaces the direct ENV/SETUP route even when its amount is zero. The HOME filter ENV DEPTH is independent. Keep this existing rule for saved-project compatibility; the PATCH OVERRIDE cue explains the behavior. An opt-in alternative could be considered separately if users find zero-depth override surprising.

RANDOM PER NOTE uses a dedicated per-track generator. Each accepted note-on selects a value held until the next note-on on that track. Polyphonic voices and kit lanes share the most recent value, including after a note-off; this reflects the existing per-track patch matrix rather than a per-voice modulation matrix. Block-rate RANDOM and random LFO use their original generator and remain unchanged.
